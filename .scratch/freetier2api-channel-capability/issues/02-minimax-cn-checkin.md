# 02: MiniMax Code 国内版签到

**What to build:** 国内版与国际版分别使用对应域名、共用有效签到流程；国内版不再因区域开关被挡住。区分本次新领与已领无新增，并保留真实失败原因。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent（实施中，产品验收尚未完成）

- [ ] 国内版凭证实际请求上游签到接口，端点按区域选择；国际版回归不退化
- [ ] 新领、已领、窗口未开、当前无活动、凭证失效、网络/上游业务异常分开
- [ ] `claim_result=1` 仅作新领回执，`2` 为已领无新增；未知/缺失回执不记成功
- [ ] HTTP 200 中的非零业务码仍报真实业务错误，不继续盲领
- [ ] 窗口时刻仅按上游明确字段/规则显示；未知时保留未知，未领取不记成功历史
- [ ] 缺凭证或 token 记凭证问题，不伪装成无活动
- [ ] 假宿主测试覆盖两区、已领、业务失败、未知回执和时间证据边界
- [ ] 部署后按首凭证预查资格，明确可领时仅领取一次；记录回执、状态与可取得的奖励数值
