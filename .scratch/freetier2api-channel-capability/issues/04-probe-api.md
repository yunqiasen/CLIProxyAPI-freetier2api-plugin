# 04: 插件测速接口与宿主凭证代理继承

**What to build:** 插件模型表与账号行共用测速接口。固定一条凭证和一个模型，仅发一次真实请求，返回状态、耗时、身份、模型和基础正文；原样保留上游 HTTP/业务码及基本报错。必要的 CPA 宿主 HTTP 桥补齐凭证代理继承，不涉及 CPA 认证文件卡片 UI。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent（实施中，产品验收尚未完成）

- [ ] 请求固定当前有效凭证身份与模型，返回成功标志、HTTP/业务码、耗时、模型、凭证与基础正文
- [ ] 上游失败原文保留，允许标注截断与秘密脱敏，不被二次文案覆盖
- [ ] 凭证不存在、vendor 归属不符或模型不符时明确报错，不静默改用其它凭证/模型
- [ ] 网络建立/TLS 失败与上游业务错误独立可见；HTTP 200 不自动记成功
- [ ] 出站优先级为请求显式覆盖 > 固定凭证出口 > CPA 全局出口；显式直连与空值继承分开
- [ ] CPA 宿主 HTTP 桥传递固定凭证出口，测速/签到/生产遵循同一继承链
- [ ] 测试覆盖成功、上游失败、身份/模型归属错误、网络失败、代理覆盖/继承/直连
- [ ] CPA 认证文件卡片页面未被改造；后端必要修正仍在范围内
